FE BAR SUBMISSION
A guard model scores every tool call before dispatch and returns a failure 
probability plus a verdict: coerce, warn, or allow. On coerce the agent rewrites 
the bad argument from the server's own declared schema — so the failure and 
its retry loop are prevented at dispatch, not diagnosed afterwards.
VP Engineering: 20.7% of agent spend recovered, agents right instead of confidently 
wrong.  Tool-server owner: a fix queue ranked by dollars — cost per failed call varies 
102x.
THE PROBLEM
Tiffin runs 6 AI agents calling MCP tool servers through the 
Databricks AI Gateway. 
When a tool rejects a semantically reasonable argument the agent 
does not fail loudly - it retries, reshapes the argument, guesses, 
and burns tokens. 
These failures return HTTP 200, so conventional error dashboards 
never see them.
TIFFIN
Food-delivery operations  ·  6 AI agents  ·  11 MCP tool servers  ·  109K wasted spend
